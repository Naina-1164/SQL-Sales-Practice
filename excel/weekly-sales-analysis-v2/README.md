# Weekly Sales Analysis V2 — Excel

The workbook `weekly_sales_analysis_v2.xlsx` contains seven days of sales, a summary using SUM, AVERAGE, MAX, MIN and COUNTIF, a column chart, and conditional formatting.

## Conditional formatting
- Green: Sales >= 2000 (Friday, Saturday).
- Red: Sales < 1500 (Monday, Wednesday).
