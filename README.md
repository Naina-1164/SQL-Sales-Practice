# SQL Sales Practice

A beginner-friendly SQL practice project created to build a strong foundation in SQL using a small sales dataset.

## Version 1 - Basic SQL Queries

This version focuses on beginner concepts:

- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- SUM()
- AVG()
- GROUP BY

## Practice Questions

1. Display all sales records.
2. Show only Electronics products.
3. Find products priced above 1000.
4. Sort products from highest to lowest price.
5. Calculate total quantity sold.
6. Calculate average product price.
7. Find category-wise total quantity sold.

## Learning Progress

This is the basic version of the project. I will improve it gradually as I learn more SQL concepts such as joins, subqueries, CTEs, and window functions.
