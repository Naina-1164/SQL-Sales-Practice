# SQL Daily Sales Filters — Beginner Practice (15 Oct 2026)

**Goal:** Filter a seven-day sales table to answer simple business questions.

**Concepts:** `WHERE`, `>=`, `BETWEEN`, `ORDER BY`, `COUNT()`, `SUM()`.

Run `daily_sales_filters.sql` in a **fresh SQLite database**.

## Expected results
- Sales >= 1800: **Saturday 2500, Friday 2100, Thursday 1800**.
- Sales BETWEEN 1500 AND 2100: **Friday 2100, Thursday 1800, Sunday 1700, Tuesday 1500**.
- Count of days with sales >= 2000: **2**.
- Total sales for days with sales >= 1800: **6400**.
